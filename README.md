# Legend Navratri Utsav 2026

A responsive, buildless event website using HTML, CSS and JavaScript.

Run `npm run dev` and open http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax validation. The deployment directory is `dist`.

Event dates, themes, venue and organiser phone numbers come from the supplied 2026 promotional artwork. Calls connect directly to the organisers; no payment processing or booking confirmation is simulated. Update prices, entry timings and a verified booking URL when provided. Gallery visuals are festival promotional artwork, not documentary event photographs.

Edit event themes in `dist/app.js`, content in `dist/index.html`, and styling in `dist/style.css`.
